# Content Drafts Handoff

This folder is for raw blog/market content drafts generated by Grok (via ContentEngine bot or direct).

## Workflow
1. Grok writes a Markdown draft here (e.g. `cedarburg-market-update-2026-11.md`) with frontmatter for title, slug, keywords, etc.
2. Claude Code watches this folder (or is prompted to pull latest from `dev`).
3. Claude formats it into the proper Next.js page/MDX under `src/app/` or as a niche page, adds SEO metadata, internal links, schema, and commits to a feature branch for review.
4. Human reviews before merging to `dev` then `main`.

## Frontmatter example
```yaml
---
title: "Cedarburg Market Update - November 2026"
slug: cedarburg-market-nov-2026
keywords: [cedarburg real estate, ozaukee county homes, market update]
summary: Brief 1-2 sentence summary
target_path: src/app/blog/cedarburg-market-nov-2026/page.tsx  # or niche_pages
---
```

Grok handles research + copy. Claude handles structure, SEO polish, and integration into the site.
